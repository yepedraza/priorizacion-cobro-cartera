# Proyecto Final Integrador — Machine Learning I

Proyecto de ML con ciclo CRISP-DM completo sobre datos reales. Python y Jupyter.

## Reglas del proyecto

- No inventar datos, fuentes, citas ni resultados. Si falta algo, preguntar o dejar `[POR COMPLETAR]`.
- No generar datos sintéticos para sustituir los datos reales.
- Sin fuga de datos: partir antes de transformar, todo en un `Pipeline`, el conjunto de prueba se consulta una sola vez.
- Semilla y versiones declaradas; rutas relativas.
- Todo uso de IA se registra en `declaracion_IA.md`: herramienta, prompt, qué se aceptó y qué se descartó.
- Escribir de modo que cada integrante pueda explicar y defender lo que se produce.
